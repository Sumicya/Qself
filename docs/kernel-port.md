# KernelSU 玻璃移植与场景交互

## 当前设计与验收边界

玻璃是内容的承载材质，而不是独立特效。底栏、入口、菜单、输入区共享 KernelBar 的 2dp 模糊、折射与中性罩色；阅读面板和输入框仍用各自 22dp 圆角，底栏和入口保留正常透镜及弹簧。

菜单采用入口附近浮层作为可逆实现选择，不视作用户已选择某个选项。使用完整矩阵定位入口，在系统栏和键盘之外就近展开；安全区变化后重算。透明外层仅负责外点关闭和返回，不先把取样背景变暗。单列内容、配置说明与操作都在内部滚动；按压使用统一轻量填色，不叠加旧水波纹和整项缩放。展开/收起以入口在面板中的投影为轴，不再无关地从屏幕中央上下移动。

开关只表示配置，不伪装设备验收结果。当前没有逐功能生效回执；构造时修改对象和进程初始化功能的即时恢复仍有边界。菜单明确提示重进页面或重启的需要；结束进程操作不会声称退出全部 QQ 进程。聊天分组/头像/测量/复用整链与其他拦截功能不包含在本轮完成声明中。

必须设备复验：明暗背景可读性、正常透镜、入口上下位置、横屏/分屏/键盘、大字体滚动和底部操作可达、开关/默认恢复、外点/返回/反复开关及热重载释放、输入与原生按钮行为。类型检查、定位纯函数和源码契约不替代这些场景。

以下保留早期移植的来源与验证记录；具体尺寸和材质以本节及源码为准。

## 当前外观调整：以用户确认与 AndroidLiquidGlass 为准

用户明确截图中的透镜形变正常，不把放大/按压胶囊改成所谓“修复”；此前已调整按钮排布、去边线、降低模糊及颜色覆盖；本轮另贯通菜单和输入区材质。截图仅是上一包的反馈，不能作为本轮新包效果已通过的证据。

数字新增上移：用当前 QQ Paint 测量 `0123456789` 的实际字形高度，上移一半，不改字号与水平中心。不按每次布局累加偏移；上移先于原生触摸区域更新。只放开该角标到所属页签之间的父级裁切，关闭具体计数或玻璃底栏时还原位置与裁切。尚无新包设备复验。

新增固定参考：[AndroidLiquidGlass `65ab177e90e5c1d8c62e70cf7755841982da65f6`](https://github.com/Kyant0/AndroidLiquidGlass/tree/65ab177e90e5c1d8c62e70cf7755841982da65f6)，实际默认分支 kmp。读取 LiquidBottomTabs / LiquidBottomTab / LiquidButton 源码，不把该库称为苹果官方 iOS 27 实现。它的 BottomTabs 示例模糊为 8dp、Button 为 2dp；按用户“降低模糊”的要求统一采用 2dp，不盲目复制 8dp。

- 设置短胶囊可见 76×64dp，与静止底栏同高、垂直中心对齐；以玻璃可见边缘计 12dp 间距，四周仍有 8dp 绘制空间。不再把最大按压/速度形变包络作为静态空白。父坐标用完整矩阵计算，LTR/RTL 对称；不足时仍上置，按压不重算位置。静止间距变小意味着高速形变时可进入这段间隙，不再声称预留完整最大包络。
- 去掉主材质与指示器的 BloomStroke 边缘高光带，也取消无用的重力监听；保留内部交互柔光、折射、色散、内阴影与原弹簧比例。AGSL 原公式哈希不改，BloomStroke 字符串仅作来源快照，不再实例化。
- 普通 QQ 内容的录制层统一中性色；强调色副本整层着色，保留抗锯齿和透明度，不直接修改真实控件的 tint/textColor。Monet 开关仍有效，关闭时采用参考示例的浅/深色蓝。基础 surface 改为示例的 #FAFAFA / #121212（40%）；前景不再叠加额外 40% surface，仅保留原有静止与按压遮罩，避免强调色被再次压暗。
- 本轮先修可直接证明的着色层与罩色顺序，保留 QQ 原图标形状，没有重绘图标。若仍需替换图形，属于后续图标绘制工作，不能把整层着色说成已经重绘。
- 未新增运行依赖，不改 QQ 真实页签/触摸/徽标绑定，不改菜单面板。无本轮 GPU 或 QQ 实机复验，不称为 iOS 27 一比一效果。

## 2026-10-17：根据用户实测修正渲染链

用户反馈数字左漂、玻璃没有完整按上游、设置按钮没有胶囊形态。此前的测试通过不能推翻这些失败证据。

### 数字定位

旧代码先清空 translationX，再把 `getLocationInWindow` 的整数窗口位置与局部宽度相减，结果直接写入局部 translationX；祖先缩放时单位不一致。现在两点均通过完整矩阵变换进入 badge.parent 坐标，再作差增量校正，不先清零；复制 QQ Paint 后显式指定 `Paint.Align.CENTER`，Y 从原始位置上移半个数字字形高度。追加 DEX 核对确认 QQ 的 initPaint 原本就设置 CENTER，所以该显式设置只是防御，不把它冒称为已证实的左漂根因。QQ onLayout 会更新 mDelegateRect，故先校正位置，再执行原生布局回调更新触摸区域，避免数字移走而命中区域留在旧位置。仍按真实计数展开、纯数字无红底，宽度随数字增长。纯逻辑测试覆盖多种宽度、窗口缩放、镜像和重复定位；不等同于 Android Matrix 实机测试。

### 绘制层对应

| 上游层 | View 移植 |
| --- | --- |
| 原始 backdrop | 录制祖先背景与前序兄弟；以 source→global→host 完整矩阵转换，避免窗口位移再叠加自身 matrix 的重复变换；背景与内容分别处理自身 scroll |
| 64dp 普通 Row | 在主栏 dispatchDraw 合成材质及 QQ 内容；普通内容不参与 1.2 倍缩放，材质单独作 `1 + 16dp/width × progress` 扩张 |
| 56dp 强调色隐藏 Row / tabsBackdrop | 调用真实 TabView 的原生 dispatchDraw 录制内容，跳过 TabView 自己的旧背景与水波纹；保留其子控件 drawChild、alpha、矩阵、动画及 display list；副本按每个页签中心作 `1 + .2 × progress` 缩放，再以强调色着色 |
| combinedBackdrop | 原始场景 + 独立 56dp 模糊/折射/40% surface + 强调色内容副本 |
| 前景指示器 | 在普通内容之后绘制，从 combinedBackdrop 取样；保留按压折射、色散、罩色、BloomStroke 与内阴影 |

不再给 host、strip 或 tab 写入材质动画用的 scale/translation；真实布局与命中区域不随按压改变。4dp 面板回弹在 Canvas 上施加，背景录制补偿该平移。指示器使用浮点 Canvas 位移，避免 RenderNode 整数位置截断；内阴影改为模糊外侧反向遮罩再裁切，不再用向下偏移的单侧残片代替。

固定尺寸/效果：64dp 栏、4dp 内边距、最小 76dp 页签、56dp 指示器、78/56 按压比例；饱和度 1.5、4dp 模糊、24dp 基础折射；指示器 10/14dp×按压进度、深度效果与 0.5 色散；1dp/2dp 双峰高光、3° 重力量化、8dp×进度内阴影。五份 AGSL 保持固定源码哈希。

弹簧保留上游阻尼/刚度与连续位置/速度，不再截掉超过 64ms 的帧间隔。速度形变改为跟踪动画位置的 VelocityTracker 结果，不再对弹簧解析导数另作一遍滤波。点击释放取消原生待发点击，再调用真实页签 performClick 一次；横拖也只在释放时点击。释放后不再由 clear() 把目标重置为尚未更新的旧选择；仅在原生选择实际改变时同步。徽标原生拖动、多指取消、纵向转交背后原生内容页的分支保留。

### 独立设置短胶囊

用户选择独立短胶囊，后续可根据实际效果改回圆形。可见尺寸 76×52dp，四周另留 8dp 绘制余量，物理布局不因按压改变。使用同一个 KernelBar 材质/按压弹簧（standalone 模式不画页签指示器），不再走旧 roundBar 渐变早退路径，也不叠加另一套水波纹或 0.96 倍 View 缩放。三线图标保持正方形比例并居中，不随胶囊宽度横向拉伸。空间不足仍置于右上方；当前菜单材质与定位见文首。
