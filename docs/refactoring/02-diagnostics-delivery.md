## 安装和首次使用

1. 先备份当前模块配置。此包保留原包名，但 CI 测试签名可能与手机已装版本不同；若系统提示签名不兼容，不要卸载 QQ 或清除 QQ 数据。
2. 安装模块后检查 LSPosed 的 QQ 作用域，完整结束并重新启动 QQ。自动热重载已关闭；不要求重新登录。
3. 从 **QQ 内**的模块设置搜索 **“上报诊断”**（辅助功能 → 实验性功能）。不要在独立模块进程中读取 QQ 的诊断存储。
4. 显式开启诊断，然后完整重启 QQ。打开摘要，先核对 `main`、`msf` 的 `INSTALL/COVERAGE` 是否有记录；无记录不表示没有上报。
5. 保持其他 QQ 模块和自动任务停用，先做正常使用/待机观察，不主动触发安全挑战。此构建改变了部分安全基线，不能用一次结果直接给此前某模块定责。
6. 若又掉线，恢复可进入设置后再手动标记，并说明实际掉线与按标记按钮之间的时间差。复制摘要前检查内容；不提供密码、验证码或登录票据。
7. 停止记录后，完整重启 QQ 才会卸除已安装的观察 Hook。清空操作不改变登录态或 O3 拦截设置。
