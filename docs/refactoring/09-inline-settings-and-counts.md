# 下展开设置、MD3 小窗与具体消息数量回归

用户对 r3091 评价为“一般”；本轮以最新的小窗/下展开要求为准，不继续把 Liquid Glass 镜头作为设置浮层的验收目标。

## 本轮修改清单

- [x] 恢复原 `cc.ioctl.hook.msg.ShowMsgCount` 注册，入口为 **聊天 → 消息工具 → 消息数量 → 显示具体消息数量**；保留原配置键，不用底栏徽标选项冒充原功能。
- [x] 数量适配按会话徽标、总消息、小程序、隐藏会话入口/列表隔离失败；新 QQ 不再准备旧版 AIO DexKit 目标。匹配已知 `updateNum` 的数字首参及继承/重载，不跳过 QQ 原方法；只替换正数文本并请求刷新，不编造获取不到的数量。
- [x] 旧数量回调也检查开关并通过统一 Hook 包装记录运行错误；关闭后不继续修改新数据。局部不支持会记录具体异常，而非宣称全部适配成功。
- [x] 底栏数字读取共用已知方法匹配；支持 long 数值，不再截断为 int；Hook 不强持有第一份 Activity 的底栏，缓存中的 View 改为弱引用。
- [x] 错误项点右侧打开可选中文本/复制；左侧仍独立开关；长按功能项也可查看状态。完整报告提供已有复制、文件分享和保存入口。
- [x] 修正包装 Context 强转 Activity 及详情工厂返回错误 Fragment；移除旧错误页监听截图/改写 FLAG_SECURE 的行为。
- [x] 初始化完成后更新当前行错误状态；脱离窗口或已回收给其他项的行不被旧回调重绑。
- [x] 首页四个大按钮替换为原地下展开列表；展开不触发导航或配置写入。保留展开状态及宿主重建恢复，显式绕过 RecyclerView 不保存子 View 层级的限制。
- [x] 设置分类使用居中、限宽限高的 MD3 小窗。默认背景透明度 **12%**，可调 **0–35%**；只改变背景，不降低文字/开关 alpha。内层列表不再铺不透明卡片覆盖窗口透明度；颜色跟随设置页系统色。
- [x] 旧玻璃偏好保留但不再控制新小窗；新透明度使用独立键，避免旧默认 0% 把新小窗继续变成实色。QQ 底栏配置仍独立。
- [x] 左侧状态区贴边、铺满行高，外侧与行共用 12dp 圆角，内侧直边；保持 ✓/×/−、48dp 宽触摸区、RTL 镜像和状态动画。
- [x] 去掉底栏硬件、回退和拖动液滴路径的边缘描边/顶部亮边。保留折射和按压反馈，不以破坏整个底栏来移除高光。
- [x] 系统关闭动画时不播放展开/状态/小窗动画；正常设置保留展开高度动画、纵向分类切换、入场与退出。

## 自检与证据边界

修正了回归中暴露的测试编译声明/状态方法可见性问题、大字号文本箭头裁切，以及复制按钮消息尚未派发便读取剪贴板的测试时序。
使用固定尺寸矢量展开图标，未缩小正文或关闭大字检查。

原生测试图使用样例数据，不是 QQ 实机截图。QQ 9.2.10 的实际未读数、每条数量路径、ColorOS 小窗视觉/帧率仍需设备验证；方法匹配测试不等于该宿主已全覆盖。
