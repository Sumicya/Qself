# 单一精简版：注册裁剪、配置承接与 MD3 Expressive

日期：2026-09-12。最新要求：常规页面使用 MD3E；玻璃只用于小窗、局部弹层等场景。本文替代之前的“设置页玻璃为核心”方向，但保留 3064 修复的测量链和大字适配。

## 交付范围

- 单一清单 `config/simplified-features.txt`，不增加完整版、切换开关或第二构建渠道。共 40 个独立条目：主源码 Hook 注册由 311 减为 34，UI 注册由 317 减为 32（两表有交集）；其余 288 个主源码独立注册条目停止加载；debug 源集附加的 5 个调试条目同样不注册。
- 保留首页日常功能、五个广告净化子项、独立 O3、只读诊断、热补丁/崩溃上报选项、主题设置及必要的消息/好友/入口基础设施，保留 CleanUpMitigation 对配置目录的清理保护，不把它当普通功能裁掉。
- 此清单是依赖审计后的首轮实现选择，不把首页 20 个快捷项冒称为用户逐项确认的白名单。群管理保留的是此前受限实现；未恢复未验证的管理写操作。
- 未纳入的实验、设备伪装、重复扩展等功能不进入 KSP 生成的 Hook/UI 数组。排除判断在生成单例引用之前完成，不是实例化全表再隐藏菜单。
- 删除非保留功能的直接早期初始化引用；四个保留消息分发器只构造保留的装饰器，消息尾注也移除对闪照/NoSeq 已裁功能的间接单例引用。取消外部模块链加载，原路径配置仍保存。
- 四个 Hook 基类、缓存管理的覆写初始化（删除缓存之前）以及早期/前台初始化入口增加注册范围检查，旧配置中的 `enabled=true` 不会绕过裁剪。未注册的内部实现组件仍是保留功能的依赖，不使用包名前缀放行新的注册功能。
- 生成注册表排序固定；跨进程初始化改为新 action、同构建检查和类名查找。拒绝旧数字索引报文，避免新旧进程把相同索引解释成不同功能；非法本地索引返回 null。
- 搜索和分类基于同一生成 UI 表；移除空分类及“开发中的功能”占位入口，保留备份、故障排查、关于。

## 配置承接

- 不删除、清空、改名或批量关闭旧功能键，不改账户配置、标记数据及未知键；不自动开启保留功能。移除 debug“启用所有功能”旧键对运行状态的强制覆盖，键本身原样保留，各功能自己的保存值重新成为依据。
- O3 的 `rq_risk_report_interceptor.enabled` 保持原值，广告总开关的各子项混合状态也保持原值。广告总开关显示 x/5，并明确需要重启，避免误认为只初始化总开关空实现就已经生效。
- `qself.settings.glass` 原值保留，首次转换时复制合法值到 `qself.overlays.glass`；已有新键优先。不合法旧数值使用柔和模式作新默认，不改旧值。
- `qself.profile.schema=1` 标记承接完成；幂等，恢复缺少标记的旧备份后可再次执行，不降级新版配置。
- 这叫“原位保留并停止加载”，不是物理删除源代码、减掉所有 APK 字节，也不是把私人配置另存一份上传。恢复备份不会重新开放已裁功能；以后增补清单可继续承接旧配置。

## 常规页面：真正的 MD3E 组件

- Material 1.14.0 的 `Theme.Material3Expressive.DayNight.NoActionBar` 在内容加载前应用，保留现有主题色选择入口。
- MaterialCardView 分类卡、MaterialSwitch 设置开关、MaterialShapeDrawable 实色容器和 Material 色彩角色；无整页折射、透明叠层或滚动玻璃刷新。
- 保留共享 SettingsListLayout/HomeItem、受限宽度测量、大字单列、等高卡片、原生搜索/返回与视图生命周期修复。
- “局部弹窗玻璃”仅控制材质选择弹窗本身；原有 QQ 液态底栏是独立局部组件，不让弹窗偏好控制 QQ 或常规页面。
