# 06 · 我的功能集与新客户端愿景

状态: 草案 v1（待用户确认增删）
日期: 2026-09-07

## 0. 愿景三原则（用户原话）

**简化 · 现代化 · 自由化**，交互形态可部分参考 Telegram。

- 简化: 去除一切非必要元素（薄带去除、菜单图标去除、外圈间隙去除——已是既有实践）；
- 现代化: 液态玻璃、纯白数字等新视觉语言（用户对 md3e 有自己的设计语言需求，视觉规范由用户出）；
- 自由化: 每个几何/行为留旋钮（GlassConfig 旋钮传统），拒绝写死。

## 1. 形态结论（探讨记录）

- QQ 协议闭源 + NT native 内核 + 风控 → 从零协议客户端不可行；
- TG 有 NagramX 是因为官方客户端开源可分叉（更正记录: NagramX 是 TG 分支，非 QQ 改包）；
- QQ 语境下"自己的客户端"的现实形态 = **模块即客户端**: 官方 QQ 为内核，
  模块层拥有全部 UI/行为自由。路线 2（自有模块壳）为既定方向，
  规模由下方清单决定。

## 3. 规模评估

- 17 项（其中 1 项待修、1 项计划、1 项调试工具）——**14 项日常在用**；
