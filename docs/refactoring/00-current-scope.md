- 旧分支个人功能集作为候选输入，不能将其所有实验功能直接认定为首版必装项。

## 稳定性与隐私目标

用户希望增强隐蔽性，降低被检测后踢下线和反复登录的风险。

工程上以最小注入、最少非必要宿主改动、移除非必要遥测、可控诊断和异常隔离为初步方向，不承诺无法被检测或永久保持登录。

- 未取得提示和对照证据前，不把掉线直接归因于 Qself 或某个第三方模块。
- 不通过隐藏安全提示、吞掉退出登录事件或伪造登录成功来声称问题解决。
- 不修改或收集登录凭据、验证码、cookie、会话票据。
- 不通过反复自动登录、反复触发安全挑战做验证。
- 未验证的网络拦截不作为默认保护措施。
- 诊断默认最少量、本地、脱敏；不得要求用户提交包含聊天正文、账号凭据的完整日志。
