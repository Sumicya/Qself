# 紧凑选项、浮层与玻璃配置

> 历史 r3081 记录：用户不认可其中的生成纹理玻璃及不完整动效。取景、系统配色和动效后续实现见 [08](08-live-overlay-and-motion.md)，不得将本页视作已通过视觉验收。

接续 r3074 能力合并；不再次精简已有功能，不修改 O3 拦截策略。

## 实现

- 开关：左侧 48dp 原生 CompoundButton 触摸区域，内含居中的 32dp 方形符号。
  ✓ 开、× 关、− 当前不支持或出错；后两者保留实际配置，辅助功能读出配置状态。
  单行最低 56dp，多行按字号展开，行间距 2dp；支持 RTL。
- 只保留工具栏搜索。搜索结果、首页分组、旧分类入口进入同一个 BottomSheetDialogFragment。
  返回分类不叠新窗口，关闭回到原页。特殊备份/关于页保留页面形态，取消横向转场。
  宿主原本禁用 Fragment 自动恢复，因此另外保存/恢复浮层分类、入口及列表位置。
- 不支持功能的开启确认在**写配置前**进行；取消不先写开再写关。
- 浮层：透明度 0–100%、纹理/纯色/蓝灰色背景、跟随/浅色/深色、三档纹理。
  设置作用于实际分类浮层的背景；选项卡片仍是不透明 MD3。
  浮层使用的是光学纹理，不声称实时采样背后页面。QQ 底栏是独立的实时采样渲染器。
- 底栏原开关左侧切换，点击说明配置：文字显示/隐藏、文字字号、未读精确数优先/99+/原生/隐藏、数字字号，
  以及独立的透明度、背景、明暗。配置直接传入 AGSL 与旧版材质路径，不只改变预览。
  保留未知数字或无法定位时的 QQ 原徽标，不把回调计数伪装成未读数。
- 按需恢复 `SimplifyBottomTab`（沿用原配置键，默认空选择）：选择隐藏页面以调整实际按钮数量，消息页保留。
  不创建虚构标签；安装仅接受已识别的 `addFrame` 签名，匹配不到报告失败，不再空操作返回成功。
  页面数量修改和总开关需完整重启；纯外观配置返回 QQ 首页时刷新。

## 本地功能记录

`功能开关与错误记录` 默认记录，可独立关闭、复制或清空；不影响 O3 观察开关。
记录 START/PID/build、安全模式、通用基类 INIT_BEGIN/END、CONFIG、设置 SWITCH、多选 OPTIONS 数量、ERROR。
错误只保留类型与最多六个代码位置，不记录异常消息、文件名、参数、消息、账号或凭证。
每个 main/msf/other 类别最多 96 条、单快照 90KB；异步队列 128、跨进程文件锁，清空/开关代次隔离旧任务。

边界：异步记录可在进程骤停时丢失尾部；不安装全局崩溃处理器，不捕获所有自定义实现或原生崩溃。
INIT_END=true 仅代表初始化返回成功。缺少 END 或频繁 PID 更换，都不能单独证明崩溃原因。
O3 新增未覆盖方法的形状与原因说明，仍不读取 payload，不把 AFTER_CALLBACK 当作实际发送或拦截结论。
