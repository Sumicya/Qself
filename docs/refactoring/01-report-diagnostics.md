# 上报诊断 v1：只读观察，不是反检测保证

状态：源码初版，尚未完成 Android 构建或真机验收。仅面向 QQ Android 9.2.10（11310）。

## 本批边界

- 当前会话分支上的增量功能，没有整合第一分支的玻璃/群日志等功能。
- 不改 QQ 的登录、退出登录、设备身份、请求参数、返回值或异常。
- 不改变旧功能 `rq_risk_report_interceptor.enabled`，只展示它的配置值。配置开启不等于 Hook 安装成功。
- 不请求任何网络接口、不解析消息体、不访问 UIN、cookie、token，不记录异常消息、堆栈或任意对象的 `toString()`。
- 不扫描全部模块、已安装应用或设备环境。

## 入口与操作

入口：模块设置 → 辅助功能 → 实验性功能 → **上报诊断（只读）**，也可搜索“上报/掉线/O3”。

1. 默认关闭，包括开发用的“全部开启”也不会自动开启此项。
2. 点击开启前展示采集范围；开启后完整重启 QQ 才能保证目标进程安装了观察 Hook。
3. 停止记录立即使后续回调/队列停止采集；已安装 Hook 要到进程重启后才卸除。诊断不会强制结束 QQ。
4. 查看/复制摘要：只复制本地元数据，明确提示分享前检查。
5. 手动标记“刚刚实际掉线”或“刚刚收到风险提醒”：只表示按按钮时的时间，不是自动检测或倒推出的掉线/服务器检测时间。界面无法访问期间不能写标记。
6. 清空记录：清空主进程/MSF 观察窗口；旧队列、旧调用在后续返回时不能显示为新窗口记录。清空不会重装 Hook，历史安装记录会一起消失。

独立模块 App 不与 QQ 共享这个存储空间，因此须从 QQ 内的模块设置访问。

## 能看到什么

- START：诊断初始化时间、PID、模块版本与固定 QQ 适配版本。不是进程真正创建时间，也不是自动掉线检测。
- COVERAGE / INSTALL：目标类是否存在、候选方法数、成功挂载数、形状不支持数和安装错误类型。
- ENTRY：观察到某个目标方法被调用，附命令标识、调用 ID。只保留下面两类命令：
  - `trpc.o3.mobile_security.*`
  - `trpc.o3.report.*`
- AFTER_CALLBACK：该观察 Hook 收到结束回调、耗时和异常**类名**。不读取返回对象或异常消息。
- USER_MARK：用户手动填写的本地时间标记。

所有事件时间为 UTC。摘要包含明确的时间格式提示。

## 不能从记录推出什么

- ENTRY 不表示原方法执行，更不表示数据已出设备或被服务器接收。
- AFTER_CALLBACK、无异常、null/void 返回，都不能当作“上报成功”。本功能不尝试判断发送成功。
- 其他 Hook 可能先短路调用；已有 O3 拦截也可能让观察到的调用没有真正发送。
- 一个请求可能先后经过两层方法，因此调用次数不是唯一网络请求数。
- 未记录到事件，不代表没有上报：可能没有命中、没有安装、类型未覆盖、被其他 Hook 提前拦截、限流或队列溢出。
- 不判断哪个模块导致平台处置。后台掉线与此前更新模块掉线仍需分别调查。

## 实现约束

- 仅主进程和 MSF 进程。
- 只对 `MsfCore.sendMessage/sendMessageInner` 与 `ChannelManager.sendMessage` 的非抽象方法做形状检查。
- 参数的**声明类型**必须提供公开、非静态、无参且返回 String 的 `getServiceCmd()`。Object 类型参数、私有字段、模糊猜测均不扩展。
- 对所有符合形状的重载逐一安装，而非只取第一个同名方法。
- 限定命令长度/标识符语法，剔除 URL 参数、换行和明显不合法文本；长数字串脱敏。命令名仍是宿主提供的元数据，分享前应复核。
- 每进程每秒最多采集 20 次匹配调用，在途关联最多 128 条，异步写队列最多 128 项。
- 网络调用线程不写日志快照，也不等待写队列；满队列丢弃并计数，不使用 CallerRunsPolicy。
- 每个进程保存最多 128 行，每行最多 480 字符。固定两个 MMKV 快照键，不生成无界文件/按 PID 无限增殖的键。
- 存储复用 QQ 进程内 ConfigManager cache，命名空间 `qself.report_diagnostics.*`。不会上传到日志平台。
- 清空采用观察窗口 epoch；启停另有 generation，避免快速停启时旧队列/旧回调混进恢复后的采集。
- 统计持久化是尽力而为；进程突然退出可能损失排队记录，采样/错误计数也可能未及时刷新。摘要额外展示当前查看进程的即时错误计数。
- INSTALL/START 是历史记录，不保证该 PID 目前仍存活。
