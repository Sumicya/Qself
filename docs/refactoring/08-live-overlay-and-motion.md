# 实际背景玻璃、系统动态配色与浮层动效

## 本轮已确认

用户明确选择：接近 Liquid Glass 的实际取景与折射；设置页取系统动态色；补齐浮层及选项动画。
r3081 的生成纹理不能满足这一要求。本轮不以修改名称、加透明度或静态截图代替实际背景采样。

## 实现边界

- 删除原 `SCENE` 生成背景。只记录模块设置 Activity 的实际 View 树到 RenderNode，之后做背景模糊、SDF 边缘折射、轻微色散与高光。
- 浮层与取景源属于不同窗口，按屏幕坐标对齐。禁止自采样、禁止采样 FLAG_SECURE 窗口。
  不做全屏截图权限请求，不读取壁纸图片，不将用户像素写入磁盘。
- 取景源变化或面板移动时更新；静止时复用背景记录。关闭、脱离窗口、停止显示时移除监听并释放 GPU 显示列表。
  没有取景源、无硬件加速、低于 API 33 或渲染失败时显示实色回退状态，不生成替代纹理。
- 设置主题默认使用 Android 12+ 系统动态色资源，不用 OEM 白名单排除 ColorOS。
  系统若只提供固定色，则如实使用该系统色；不声称已经验证用户设备的壁纸更新行为。
  保留明确的系统/手动主题色选择，取消手动选择不改变模式。恢复设置窗口时检查系统色是否变化。
- 浮层进入使用 Material 主题时长/缓动，关闭与手势退出使用 BottomSheet 动画。
  进入/拖动/关闭时连续调整镜头圆角和折射强度，不只移动一张静态图片。
  分类进入/返回使用纵向 MaterialSharedAxis，保留上一层滚动位置，不创建横向页面栈。
  方形开关状态渐变/缩放不延迟配置写入；回收绑定不重播；关闭系统动画时立即切换。
- 普通页面及选项卡片仍是不透明 MD3，玻璃只应用于浮层背景。QQ 底栏为已有独立渲染器，本轮不扩展其动画范围。

## 必须验证

1. 实际源由红变蓝，取景结果同步改变，不能保持预制纹理。
2. 实际色块边界经过镜头时，比仅模糊的参考图发生更明显位移。
3. 无源/自采样回退，不把 shader 编译成功当作已经显示真实效果。
4. 系统 primary 与 framework 壁纸动态色资源一致。
5. 动画中的 checked 已是目标状态；不会重复调用监听；绑定会取消旧动画。
6. 保留原全宽、大字、RTL、亮暗对比、配置及功能回归。
