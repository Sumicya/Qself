# 设计准则（Design Principles）

本文档只沉淀跨迭代可复用的设计规律、几何规范与用户明确确认的偏好，不记录临时调试参数。

## 1. 悬浮玻璃与安全区重定位
- **去底色必重定位**：任何移除顶栏或底栏实色安全区背景的改动，必须同步完成三件事：
  1. 将承载内容的滚动容器（如 `RecyclerView`）设为 `clipToPadding = false`，允许内容在悬浮玻璃胶囊后方连续透出；
  2. 为悬浮胶囊预留明确的外边距（水平安全边距 `8dp`，顶/底按状态栏与导航栏内缩定位）；
  3. 清除原宿主按旧全宽坐标挂载的 `TouchDelegate`，将点击命中区精确绑定到重定位后的左、中、右胶囊几何区域。
- **日夜双模式对比度与无描边径向高光**：
  - 夜间模式下禁止保留专为浅色实底设计的深灰图标或暗色文字；
  - 顶栏、输入栏、快捷栏、搜索栏及二级页导航栏在夜间模式下统一使用高对比度浅色主视觉（主标题/主图标 `#F2F5FA`～`#F5F7FA`，次级信息 `#B8C2D0`～`#D5DCE8`，占位提示 `#A6B0C0`）；
  - 全仓严禁使用 `Paint.Style.STROKE` 给玻璃或气泡画静态描边，统一采用 `Kyant0/AndroidLiquidGlass` `InteractiveHighlight`（`INTERACTIVE_HIGHLIGHT_SHADER` + `BlendMode.PLUS`）按压/长按径向柔光高光，玻璃模糊默认 `1dp` 并提供 `0~15dp` 滑条实时调节。

## 2. 消息行与气泡几何
- **收发对齐与头像粘性**：
  - 居中系统灰字提示保持水平居中，不套用收发气泡约束；
  - 他人消息居左对齐（左侧头像），自己消息居右对齐（右侧头像）；
  - 单条独立消息头像保持原生顶对齐，仅同发送人连续多条消息（`>= 2`）在组上下边界内执行粘性滚动合并；
  - 他人与自己在连发组首均显示头衔与昵称 ID（他人左对齐、自己右对齐），组内续条自动折叠冗余昵称与重复头像。
- **单层气泡与四向等距内边距**：
  - 每条消息只允许存在唯一一层外层圆角气泡（四角全圆角 `17dp`，连发不切直角）；
  - 气泡四向内边距严格统一为 `5dp`（`left = 5dp, right = 5dp, top = 5dp, bottom = 5dp`），必须同时清零宿主皮肤内边距数据类（`skin.padding.j` / `skin.padding.h`）、内层包装容器内边距与四向 `margin`，并关闭文本视图（`TextView` 与 `FasterTextView`）的 `includeFontPadding`；
  - 被回复/引用消息与回复正文共享同一个外层气泡，禁止在被回复区域再套内层背景方框或左侧竖条。
- **消息外部时间**：
  - 格式化时间戳统一挂载于消息气泡容器底部外侧，以适配文本、图文、回复、图片、表情、卡片等全部消息类型；
  - 他人时间戳左对齐（`START`），自己时间戳右对齐（`END`），且不得触发父级垂直 `LinearLayout` 对同容器兄弟视图的宽度压缩。

## 3. 输入栏与跨页面一致性
- **独立全胶囊形态**：输入框与发送按钮各自按自身高度的一半（`height / 2`）独立裁切为全胶囊，不给整个底栏铺通栏实色背景，并拦截宿主兼容层与异步任务对背景的回写。
- **跨页面视觉延续**：主页顶/底栏、聊天页顶/底栏、二级页面导航栏（`QUISecNavBar`）与搜索栏（`QUISearchBar`）共享同一套悬浮玻璃胶囊与夜间提亮准则。
